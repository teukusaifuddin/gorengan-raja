# Sistem Gorengan Raja

Alat perencanaan bisnis Gorengan Raja dalam satu halaman: Dashboard, Outlet, Resep & HPP, Rencana vs Nyata, serta simulasi Mitra & Pusat.

- Semua angka awal adalah **asumsi contoh**, bukan hasil usaha nyata, bukan janji laba, dan bukan penawaran waralaba.
- Data yang diisi tersimpan di browser masing-masing pengguna (localStorage), tidak dikirim ke server mana pun. Gunakan tombol "Unduh cadangan data" secara berkala.
- Situs statis: cukup `index.html`, tanpa server atau proses build.
